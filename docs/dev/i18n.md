# i18n Y Gestion De Textos

Este documento describe como Notifica gestiona traducciones y textos de UI.

Los inventarios de trabajo del pase anterior de i18n/rewording viven en [working/](./working/):

- [working/i18n-checklist.txt](./working/i18n-checklist.txt)
- [working/rewording-candidates.txt](./working/rewording-candidates.txt)

## Configuracion Actual

Las traducciones viven en:

- `src/locales/es.ts`
- `src/locales/en.ts`

La app soporta:

- espanol
- ingles
- seleccion automatica segun idioma del sistema

## Reglas

- No hardcodear textos visibles en componentes si pertenecen a i18n.
- Mantener claves consistentes entre todos los archivos de idioma.
- Actualizar todos los idiomas soportados al anadir una clave.
- Usar nombres de clave claros y agrupados por feature o superficie.
- Validar layout cuando cambie la longitud de textos.

## Editar Textos Existentes

1. Localizar la clave existente en `src/locales/`.
2. Actualizar `es.ts` y `en.ts`.
3. Revisar todos los lugares donde se usa la clave.
4. Validar la UI en ambos idiomas si puede cambiar el layout.

## Anadir Textos Nuevos

1. Definir una clave clara.
2. Anadirla a todos los archivos de idioma soportados.
3. Usar `useI18n()` y `t('clave')` en el componente.
4. Validar fallback.
5. Revisar mobile si el texto aparece en UI compacta.

## Anadir Un Idioma

1. Copiar un archivo de locale existente.
2. Traducir todas las claves manteniendo estructura.
3. Registrar el nuevo locale en la configuracion i18n.
4. Anadir soporte de seleccion en UI si procede.
5. Validar fallback y deteccion por idioma del sistema.

## Notas

Los inventarios de rewording son artefactos de trabajo, no documentacion canonica. Usarlos como referencia al revisar terminologia, pero mantener decisiones finales en los archivos de locale y en este documento.
