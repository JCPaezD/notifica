# Documentacion de Desarrollo de Notifica

Esta carpeta contiene la documentacion activa de desarrollo de Notifica.

Puntos de entrada principales:

- [Notifica-Roadmap.md](./Notifica-Roadmap.md): roadmap vivo, fase de fortificacion y backlog actual.
- [dev-notes.md](./dev-notes.md): notas vigentes de desarrollo y decisiones duraderas.
- [architecture.md](./architecture.md): arquitectura actual, deuda conocida y direccion del refactor.
- [maintenance.md](./maintenance.md): flujo local, validaciones, checks y mantenimiento del repo.
- [release-process.md](./release-process.md): proceso de release PWA y Android.
- [i18n.md](./i18n.md): gestion de traducciones y textos.
- [known-issues.md](./known-issues.md): bugs conocidos, limitaciones de plataforma y trabajo diferido.

Material historico y de trabajo:

- [archive/](./archive/): roadmap y notas de desarrollo historicas completas.
- [working/](./working/): inventarios temporales y artefactos de trabajo.

## Reglas de Mantenimiento

- Mantener los documentos activos faciles de escanear.
- Mover narrativas historicas largas a `archive/`.
- Mantener inventarios temporales en `working/`.
- Preferir enlaces antes que duplicar la misma decision en varios documentos.
- Actualizar este indice cuando se anadan o muevan documentos de desarrollo.
